## A practical workspace for multiple data sources

GoNavi brings common database and middleware workflows into one native desktop application. Instead of switching between separate tools, you can use one workspace to connect to relational databases, caches, message queues, and analytical systems.

Built-in connections cover PostgreSQL, MySQL, Oracle, Redis, Kafka, RabbitMQ, and more. ClickHouse and other optional sources can be connected through the [driver agent](/en/docs/data-sources/).

## Connect, inspect, and work in one flow

Create a connection with a host or URI, configure SSH tunnelling or a proxy when needed, then save and reuse it from the connection sidebar. GoNavi also supports importing and exporting connection settings as JSON, which helps teams move between machines without recreating every connection.

For relational databases, the usual workflow combines schema browsing, SQL querying, data editing, and export or backup tasks. Redis is optimized for key browsing and command execution, while message queues expose their relevant resources and consumer-group information in the same workbench.
