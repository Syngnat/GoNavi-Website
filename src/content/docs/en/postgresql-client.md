## PostgreSQL workflows in a native desktop client

GoNavi is a desktop workspace for connecting to and working with PostgreSQL. Keep frequently used databases in the connection sidebar, browse database objects, and open SQL workspaces without moving between browser tabs or separate utilities.

## Connect PostgreSQL your way

You can configure PostgreSQL with a host or URI. For private networks and remote environments, GoNavi also supports SSH tunnelling and proxy settings. Connection settings can be imported or exported as JSON when you need to reuse them across machines or share an agreed configuration.

Read the [connection configuration guide](/en/docs/connections/) for the available options, then follow the [quick start](/en/docs/quick-start/) to validate the connection.

## Browse, query, and deliver data

PostgreSQL belongs to GoNavi's relational-database workflow: browse schemas and objects, write and run SQL, inspect or edit data where supported, and use export or backup tools for delivery work. This makes it useful for development, troubleshooting, and everyday operations in the same desktop environment.

For a wider overview of available integrations, visit [supported data sources](/en/docs/data-sources/) or return to the [multi-database workbench](/en/docs/database-workbench/).
