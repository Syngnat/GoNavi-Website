# Quick Start

1. Download the right package for your platform and launch GoNavi.
2. Confirm the current version from the homepage or download page.
3. Create a connection with host, port, authentication, and optional SSH or proxy settings.
4. Open the query workspace and run your first SQL statement or browse the object tree.

## Recommended Path

- Solo developers: start with a local or staging database first.
- Teams: align naming, export, and review conventions early.
