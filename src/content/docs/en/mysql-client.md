## A focused MySQL desktop workflow

GoNavi provides a native desktop workspace for MySQL connections and daily database tasks. Save commonly used environments, browse schemas and tables from the sidebar, and keep SQL work close to the data you are inspecting.

## Set up reusable MySQL connections

Connect with a host or URI, and use SSH tunnelling or a proxy when your environment requires it. You can also import and export connection settings as JSON, making it easier to restore a local setup or apply a shared team configuration.

See [connection configuration](/en/docs/connections/) for the setup choices and [quick start](/en/docs/quick-start/) for a first connection walkthrough.

## Work from exploration to delivery

MySQL follows GoNavi's relational-database workflow: browse schemas and objects, query with SQL, inspect or edit data where supported, and use export or backup tools when preparing results for others. The result is one tool for ordinary development, investigation, and operations work.

Explore [supported data sources](/en/docs/data-sources/) or compare workflows in the [multi-database workbench](/en/docs/database-workbench/).
