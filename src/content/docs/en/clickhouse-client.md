## Bring ClickHouse into the GoNavi workbench

ClickHouse is available in GoNavi through the optional driver agent. This lets teams working with columnar analytics use the same desktop workspace that they use for other databases, caches, and message queues.

## Install the optional driver before connecting

Set up the driver agent first, then create a ClickHouse connection in GoNavi. The [supported data sources guide](/en/docs/data-sources/) explains which integrations are built in and which require an optional driver, while [connection configuration](/en/docs/connections/) covers the shared connection options.

## Keep analytics close to the rest of your data work

Once connected, ClickHouse can sit alongside PostgreSQL, MySQL, Redis, and Kafka in the same connection workspace. Use the [multi-database workbench](/en/docs/database-workbench/) for the overall approach, or read [quick start](/en/docs/quick-start/) before adding the first source.
