## A native workspace for Kafka exploration

GoNavi brings Kafka into the same desktop workbench as your databases and caches. Store Kafka connections with the rest of your environments, then open the resources you need without switching to another tool for basic inspection.

## Browse topics and check consumer groups

After connecting to Kafka, you can browse topics and inspect consumer-group information. For message-queue workflows, GoNavi keeps the relevant resource browser and operational context together, which is useful when investigating integrations or checking the state of a service.

Start with [connection configuration](/en/docs/connections/) if you need URI, SSH, proxy, or JSON import options. The [quick start](/en/docs/quick-start/) explains the general connection flow.

## See the rest of the workspace

Kafka is one of GoNavi's built-in sources. See [supported data sources](/en/docs/data-sources/) for the current integration list, or return to the [multi-database workbench](/en/docs/database-workbench/) for the broader workflow.
