# Install & Updates

## Installation

- Windows: prefer the `.exe` desktop installer.
- macOS: pick the `.dmg` that matches your architecture.
- Linux: choose the standard build or the WebKit-compatible build for your environment.

## Update Policy

- Stable releases ship through GitHub Releases.
- `dev-latest` is a prerelease channel for validation, not a production default.

## Recommendations

1. Align the team on the same version before sharing workflows.
2. When an upgrade feels wrong, verify drivers and connection settings first.
