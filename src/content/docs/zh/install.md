# 安装与更新

## 安装方式

- Windows：优先使用 `.exe` 安装包。
- macOS：根据芯片架构选择合适的 `.dmg`。
- Linux：根据环境选择标准包或带 WebKit 兼容层的构建。

## 更新策略

- 正式版通过 GitHub 发布页提供稳定版本。
- `dev-latest` 预发布用于内部验证，不建议直接用于生产场景。

## 建议

1. 团队内先统一版本口径，再开始共享截图、导出或排障步骤。
2. 遇到升级异常时，优先核对驱动与连接配置是否仍然兼容。
