GoNavi 把常见连接能力收敛到同一工作流里，减少不同数据库之间的心智切换。

## 连接输入方式

- 主机 / 端口 / 数据库名
- URI（支持生成与解析）
- 用户名 / 密码
- SSH 隧道
- 代理设置

## 连接导入导出

连接配置支持 **JSON 导入 / 导出**，便于在团队成员之间共享连接清单，或在多机之间迁移配置。

## 驱动扩展

- **可选驱动代理**：部分数据源通过驱动管理器按需安装启用，详见[数据源支持](/zh/docs/data-sources)
- **Custom Driver + DSN**：通过自定义 Driver 与 DSN 接入更多 GoNavi 未内置的数据源

## 实践建议

1. 把高频数据库放在同一命名约定下，配合 JSON 导出便于团队共享。
2. 对需要跳板机的环境，优先走 SSH 隧道而不是临时手工转发。
3. 对预发和生产环境保持明确区分，避免误连。
