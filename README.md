# GoNavi Website

GoNavi 官网独立前端工程，和桌面客户端仓库并行维护。

## 技术栈

- React 18
- TypeScript
- Vite
- React Router
- Vitest

## 本地开发

```bash
npm install
npm run dev
```

默认开发地址由 Vite 提供，首版页面包括：

- `/zh` 与 `/en` 首页
- `/zh/download` 下载页
- `/zh/changelog` 更新日志页
- `/zh/docs` 文档区
- `/zh/roadmap` 路线图与社区页

## 质量命令

```bash
npm test
npm run build
```
